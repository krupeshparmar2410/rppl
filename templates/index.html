Industrial AI Features

Enterprise-grade transformer monitoring powered by machine learning and edge computing.

🧠
MongoDB Normalization
Utilizes a normalized schema design with a master transformers details collection and a telemetry transformer_history table.
📡
Feature Engineering
Derived electrical variables (KW, KVA, KVAR, Phase Imbalances) are computed using validated grid formulas and logged under estimated features.
⚠️
Fault Priority System
Classification of incident urgency into P1 (Emergency), P2 (High), P3 (Medium), and P4 (Low) to assist dispatch response times.
🌡️
Future IoT Ready
Database schema supports future ESP32 integration for on-field temperature, OTI, OLI, THD, humidity, and vibration parameters.
