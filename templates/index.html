Industrial AI Features

Enterprise-grade transformer monitoring powered by machine learning and edge computing.

🧠
AI Health Classification
Random Forest & XGBoost models trained on 19,000+ sensor readings classify transformer health into Normal, Warning, or Critical states with 97%+ accuracy.
📡
Real-time Sensor Fusion
Merges 5 sensor streams — CurrentVoltage, Overview, Power, PowerFactor, TotalPower — into a unified 32-feature real-time analysis pipeline.
⚠️
Anomaly Detection
Isolation Forest unsupervised anomaly detection identifies unusual transformer behaviour patterns before they escalate into failures.
🌡️
Thermal Stress Analysis
IEC/IEEE-based health labeling rules monitor OTI, voltage imbalance, and thermal stress factors to predict transformer degradation trajectories.
📊
Feature Engineering
Advanced feature engineering derives V_imbalance, I_imbalance, Thermal_stress, PF_drop, Load_level, and rolling OTI trends for superior model performance.
🔮
Predictive Maintenance
End-to-end pipeline: load sensor CSVs → engineer features → train ML → detect anomalies → classify health → generate maintenance recommendations.
